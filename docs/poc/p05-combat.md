# PoC 05 — 攻击交互

## 验证目标

实现完整的攻击交互流程：选择目标 → 显示命中率 → 确认攻击 → 结算反馈。

## 战斗公式

```
命中率 = 基础命中率(55%) + 攻击者命中加成 + 战役修正 - 防御者地形加成 - 距离惩罚

距离惩罚 = (距离 - 1) * 4%
命中率范围 = clamp(5%, 92%)
```

## 伤害结算

```
if (命中):
  伤害 = baseAttack * 6 > 0 ? 暴击判定? : 1
  暴击判定: 25% 概率 -> 伤害 = min(2, 目标当前HP)
else:
  伤害 = 0

突击兵种对全掩体目标: 直接造成 2 点伤害（跳过命中/暴击）
```

## 交互流程

```
1. 玩家选择己方单位（未行动）
2. 显示可攻击范围（红色高亮）
3. 玩家点击可攻击范围内的敌方单位
4. 弹出战斗预览面板（命中率、预期伤害）
5. 玩家确认攻击
6. 播放攻击动画/效果
7. 更新双方状态（HP、阵亡判定）
8. 攻击方标记为已行动
```

## 实现步骤

1. 实现 `calcAttackRange()` — 获取单位可攻击的敌方单位列表
2. 实现 `resolveCombat(attacker, defender, campaignState)` — 纯函数
3. 实现攻击范围可视化（红色高亮）
4. 实现战斗预览 UI（命中率、伤害）
5. 实现攻击动画（例如：闪烁/弹道效果）
6. 实现阵亡判定与移除
7. 实现反击逻辑（远程攻击不反击、近战攻击被反击）

## 关键技术

- 纯函数结算：`resolveCombat` 不修改状态，返回结算结果供调用方处理
- 范围分离：移动范围和攻击范围分别计算，不可同时显示
- 反击规则：近战攻击承受 50% 反击伤害；远程攻击无反

## 验收标准

- [ ] 选择己方单位后可查看攻击范围
- [ ] 点击可攻击目标显示战斗预览
- [ ] 命中率计算正确（受距离/地形/攻防修正）
- [ ] 确认后执行伤害结算
- [ ] 单位 HP 降至 0 后从地图移除
- [ ] 攻击后单位标记为已行动
