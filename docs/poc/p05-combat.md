# PoC 05 — 攻击交互

## 验证目标

实现完整的攻击交互流程：选择目标 → 显示命中率 → 确认攻击 → 结算反馈。

## 战斗公式

```
命中率 = 基础命中率(55%) + 攻击者命中加成 + 战役修正 - 防御者地形加成 - 距离惩罚

距离惩罚 = (距离 - 1) * 4%
命中率范围 = clamp(5%, 92%)
```

## 伤害结算

```
命中判定:
  掷骰 r0 = random(0, 1)
  if r0 <= 命中率 -> 命中 = true
  else -> 命中 = false

伤害计算:
  if 突击兵种 AND 目标地形.isFullCover:
    基础伤害 = 2                        // 跳过命中/暴击
  elif 命中:
    基础伤害 = baseAttack * 6
    暴击判定: 掷骰 r1 = random(0, 1)
              if r1 <= 0.25 -> 暴击伤害 = min(2, 目标HP)
              else -> 普通伤害 = 1
  else:
    基础伤害 = 0

反击伤害（仅近战攻击 & 目标存活）:
  反击命中率 = 基础命中率(55%) - 攻击者地形防御加成
  反击伤害 = 反击命中 ? 1 : 0
```

## 交互流程

```
1. 玩家选择己方单位（未行动）
2. 显示可攻击范围（红色高亮）
3. 玩家点击可攻击范围内的敌方单位
4. 弹出战斗预览面板（命中率、预期伤害、反击预判）
5. 玩家确认攻击
6. 播放攻击动画/效果
7. 更新双方状态（HP、阵亡判定）
8. 若攻击者为近战且目标存活，执行反击
9. 攻击方标记为已行动
```

## 战斗公式参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基础命中率 | 55% | 无任何修正时的基准命中率 |
| 攻击加成 | `attacker.baseAttack * 6` | 正向影响暴击触发前的基准伤害 |
| 战役修正 | `campaignState.hitMod` | 由华野战力动态决定，范围 +5% ~ -12% |
| 地形防御 | `targetTerrain.defenseBonus * (-8%)` | 每个防御点减 8% 命中率 |
| 距离惩罚 | `(distance - 1) * 4%` | 每多 1 格减 4% |
| 射程限制 | 不可攻击 `attackRange` 外的目标 | 炮兵 3，步兵/骑兵 1 |

## 近战 vs 远程

| 维度 | 近战（步兵/骑兵/突击兵） | 远程（炮兵） |
|------|------------------------|-------------|
| 攻击距离 | 1 格 | 3 格 |
| 反击 | 承受 50% 基本伤害的反击 | 无反击 |
| 全掩体目标 | 突击兵种可破障，其余不可 | 不可攻击 |
| 地形防御影响 | 目标防御加成 | 目标防御加成减半 |

## 实现步骤

1. 实现 `calcAttackRange(unit, battlefield)` — 获取可攻击的敌方单位列表
2. 实现 `resolveCombat(attacker, defender, campaignState, terrainMap)` — 纯函数
3. 实现攻击范围可视化（红色高亮）
4. 实现战斗预览 UI（命中率、伤害、反击伤害）
5. 实现攻击动画（例如：闪烁/弹道效果）
6. 实现阵亡判定与移除
7. 实现反击逻辑（按近战/远程区分）
8. 实现审计日志记录（记录 `COMBAT_RESULT` 事件，为 PoC 13 提供数据源）

## 关键技术

- 纯函数结算：`resolveCombat` 不修改状态，返回 `CombatResult` 供调用方处理
- 范围分离：移动范围和攻击范围分别计算，不可同时显示
- 反击规则：近战攻击承受 50% 基础伤害的反击；远程无反
- 审计埋点：每次攻击结算结果写入 `AuditEntry`（参见 PoC 13）

## 验收标准

- [ ] 选择己方单位后可查看攻击范围（红色高亮）
- [ ] 点击可攻击目标显示战斗预览（命中率/伤害/反击）
- [ ] 命中率计算正确（受距离/地形/攻防/战役修正）
- [ ] 确认后执行伤害结算
- [ ] 近战攻击触发反击，远程攻击无反
- [ ] 单位 HP 降至 0 后从地图移除
- [ ] 攻击后单位标记为已行动
- [ ] 每次攻击记录到审计日志（`COMBAT_RESULT`）
