# PoC 12 — 双模式架构

## 验证目标

互动剧本模式 + 兵棋推演模式共用同一引擎，验证共享模型层的可行性。

## 模式定义

| 维度 | 互动剧本模式 | 兵棋推演模式 |
|------|-------------|-------------|
| 地图 | 固定预设 | 可编辑/随机生成 |
| 单位部署 | 预设初始位置 | 玩家自由部署 |
| 目标 | 预设战役目标 | 自定义目标 |
| 情报 | 预设情报卡序列 | 动态生成 |
| 事件 | 脚本事件链 | 无脚本事件 |
| 复盘 | 支持剧情复盘 | 支持数据复盘 |

## 共享架构

```
                +------------------+
                | Application Layer |  (模式无关)
                +--------+---------+
                         |
            +------------+------------+
            |                         |
   +--------v--------+      +--------v--------+
   | Script Mode     |      | Wargame Mode     |
   | Controller      |      | Controller       |
   +--------+--------+      +--------+---------+
            |                         |
            +------------+------------+
                         |
                +--------v---------+
                |   Domain Model    |  (共享模型层)
                |                   |
                | - HexGrid         |
                | - Unit / UnitType |
                | - CombatResolver  |
                | - TurnManager     |
                | - IntelSystem     |
                +---------+---------+
                          |
                 +--------v--------+
                 |   Data Layer     |  (JSON 配置)
                 | - Campaign       |
                 | - Map            |
                 | - Units          |
                 | - Events         |
                 +-----------------+
```

## 实现步骤

1. 将 P0-P1 的核心模型提取为共享库（mode-independent）
2. 实现模式选择路由
3. 实现互动剧本模式控制器（预设事件流）
4. 实现兵棋推演模式控制器（自由部署 + 自定义目标）
5. 验证模式切换不丢失核心状态
6. 验证两种模式共用战斗/移动/地形逻辑

## 关键技术

- 策略模式：核心引擎通用，模式控制器为具体策略
- 配置驱动：战役数据全量外置到 JSON
- 事件系统：剧本模式使用事件队列，推演模式使用随机事件生成器

## 验收标准

- [ ] 两种模式均可正常游戏
- [ ] 模式切换后核心引擎一致（移动/战斗/地形算法相同）
- [ ] 剧本模式的事件链按预期触发
- [ ] 推演模式支持自定义部署
- [ ] 新增一种模式只需新增控制器，无需修改核心模型
