# PoC 03 — 地形系统

- **依赖**：p01 六角格地图
- **被依赖**：p02（移动），p05（战斗）

## 验证目标

实现多种地形类型影响移动力与防御，验证地形对游戏策略的实质性影响。

## 地形类型

| 地形 | 移动消耗 | 防御加成 | 全掩体 | 特殊 |
|------|---------|---------|--------|------|
| 平原 | 1 | 0 | 否 | 无 |
| 村庄 | 1 | +1 | 否 | 无 |
| 城镇据点 | 2 | +2 | 否 | 无 |
| 河流 | 4 | 0 | 否 | 可通过 |
| 核心据点 | 3 | +4 | 是 | 仅突击兵种可进入 |

## 数据模型

```
TerrainType: enum { PLAIN, VILLAGE, TOWN, RIVER, CORE_FORT }

TerrainProps {
  moveCost: number
  defenseBonus: number
  isFullCover: boolean
  isCore: boolean
}

// 地形配置表
TERRAIN_CONFIG: Record<TerrainType, TerrainProps>
```

## 实现步骤

1. 定义地形枚举和属性映射表
2. 实现地形 → 颜色/样式的视觉映射（平原绿、村庄褐、河流蓝等）
3. 地形配置外置（JSON/常量文件，与渲染层分离）
4. 生成预设地形布局（JSON 中定义每格地形类型，手动编辑 JSON）
5. 验证不同地形对移动范围的影响（见 PoC 02）
6. 验证不同地形对防御的影响（见 PoC 05）

## 关键技术

- 数据驱动：地形属性集中配置，不硬编码
- 视觉-机制一致性：地形颜色传递功能含义（绿色=安全、蓝色=阻隔、褐色=掩护）
- 可扩展：添加新地形只需新增枚举值和属性配置

## 验收标准

- [ ] 5 种地形在网格上可区分渲染
- [ ] 地形消耗正确影响 BFS 移动范围
- [ ] 防御加成正确影响命中率计算
- [ ] 全掩体阻挡非突击兵种的远程攻击
- [ ] 新增一种地形只需改配置文件
