# PoC 10 — 命令签署

## 验证目标

签署命令不可逆、动画签名、锁定全局操作。

## 设计意图

签署命令是回合制的"决定时刻"——一旦签署，无法撤销。这个过程需要通过仪式感让玩家感受到决策的重量。

## 签署流程

```
1. 玩家完成单位操作后，进入"命令签署"阶段
2. 显示最终命令摘要（所有单位行动总览）
3. 点击"签署命令"按钮
4. 播放签名动画（笔画逐笔出现）
5. 签署完成 → 全局 UI 锁定
6. 进入执行阶段（PoC 11）
```

## 签名动画技术方案

```
function animateSignature(canvas, commandText):
  // 1. 在 Canvas 上绘制毛笔签名
  // 2. 笔画逐笔出现（每笔 200ms）
  // 3. 总时长约 1-1.5 秒
  // 4. 完成后显示"已签署"印章
```

## 锁定状态

| 元素 | 签署前 | 签署后 |
|------|--------|--------|
| 单位选择 | 可操作 | 禁用 |
| 移动/攻击 | 可操作 | 禁用 |
| 情报板 | 可操作 | 只读 |
| 命令面板 | 可编辑 | 只读 |
| 结束回合 | 可用 | 禁用 |
| 地图 | 可交互 | 只读 |

## 实现步骤

1. 实现命令摘要面板（显示本回合所有已执行操作）
2. 实现签署按钮和确认弹窗（二次确认）
3. 实现 Canvas 签名动画
4. 实现签署后全局 UI 锁定
5. 实现"已签署"状态视觉标记（印章/边框）

## 验收标准

- [ ] 签署前可正常操作单位
- [ ] 签署命令有二次确认弹窗
- [ ] 签名动画流畅（逐笔出现）
- [ ] 签署后所有 UI 锁定不可操作
- [ ] 有清晰的"已签署"视觉反馈
