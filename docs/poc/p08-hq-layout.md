# PoC 08 — 指挥所布局

## 验证目标

实现三栏指挥所 HQ 布局：情报板 + 战场地图 + 命令面板。

## 布局结构

```
+------------------------------------------+
| 标题栏 | 态势信息 | 时间/回合计数器        |
+----------+----------------+---------------+
| 情报板   |   战场地图      | 作战命令面板   |
| (左栏)   |   (中栏)       | (右栏)        |
| 220px    |  自适应(min500) | 260px         |
|          |                |               |
| - 情报卡 | - 六角格网格    | - 当前兵力    |
| - 可信度 | - 己方/敌方单位 | - 计划选择    |
| - 采纳/  | - 地形颜色      | - 命令文本    |
|   忽略   | - 态势标绘      | - 签署按钮    |
+----------+----------------+---------------+
| 底部通信栏 | 电台状态 / 日志 / 快捷键       |
+------------------------------------------+
```

## 布局要求

- 基准宽度：最小 1100px，最大 1600px
- 响应式断点：<1100px 压缩左栏（220px → 160px），<768px 切换为单栏堆叠布局
- 中栏自适应填充剩余空间
- 三栏均可独立滚动
- 顶部状态条显示回合数、战斗力、决心值

## 实现步骤

1. 实现三栏 CSS Grid / Flexbox 布局
2. 实现响应式断点（1100px / 768px）
3. 实现顶部态势栏（回合计、华野战力、工事强度）
4. 实现底部通信栏（电台信号指示，含信号状态 dot：绿/黄/红）
5. 实现各面板的基础占位内容
6. 实现面板间的数据联动（地图选中单位 → 右栏显示详情）

## 交互约束

- 情报板：可多选情报卡，选中的情报影响地图可见性
- 地图：点击选中单位/格子，双击聚焦
- 命令面板：随选中单位动态更新

## 验收标准

- [ ] 三栏布局完整，视觉比例正确
- [ ] 窗口缩放时中栏自适应
- [ ] 各面板内容独立，不溢出
- [ ] 选中地图单位后右栏显示对应信息
- [ ] 底部通信栏显示电台信号状态（绿/黄/红 dot）
- [ ] 风格统一（深木色背景、羊皮纸卡片）
